## 标准更新流程

### 1. 采集（可选，有新热度时）

```powershell
cd D:\PCCodes\word\novel-heat
node scripts/crawl/run.js --sources=ciweimao,sfacg,qidian,jjwxc,bilibili_manga --limit=50
npm run build-data
```

### 2. 同步到本站 JSON

```powershell
cd D:\PCCodes\word\次元热度
node scripts/sync-from-novel-heat.js
```

产出：`data/public/tags-latest.json`、`tags-series.json`、`meta.json`、`acg-dict.json` 等。

### 3. 覆盖同步到 Pages 仓库（保留 ai-exam）

只同步站点文件，**不要**把 `data/raw/` 推进公开仓库：

```powershell
$src = 'D:\PCCodes\word\次元热度'
$dst = 'D:\PCCodes\blog\hugo-site\site'
$items = @('css','data\public','js','about.html','index.html','README.md','tag.html','tagheat-anime-bg-light.png','tagheat-anime-bg.png','tagheat-quill.svg')
foreach ($i in $items) {
  Copy-Item (Join-Path $src $i) (Join-Path $dst $i) -Recurse -Force
}
```

### 4. 提交并推送

```powershell
cd D:\PCCodes\blog\hugo-site
git add site/README.md site/about.html site/data/public/ site/css site/js site/*.html site/*.png site/*.svg
git commit -m "Refresh TagHeat public data for Pages."
git push origin main
```

推送 `main` 后，Actions（`.github/workflows/deploy.yml`）会把 `./site` 发布到 Pages。
