Help

热榜界面符号与阅读口径，随时可来对照。

默认打开的是细分风向综合榜；同人/IP、频道与各平台分源请用上方 Tab 切换。

榜单怎么读

分数条
当前榜单区间的相对刻度，用来对比本榜内高低，不是跨榜绝对分。
默认榜
细分风向（排除频道 / 粗题材）。频道类标签在「频道/粗题材」Tab。
单源发现 / 多源共识
表示覆盖可信度：只在一个源命中为「单源发现」；多个源同时命中为「多源共识」。
圆点（覆盖）
每个点对应一个采集平台；实心表示该标签今日在该平台上榜。
Δ
相对昨日排名变化。首日快照或无对照日时显示「—」或 NEW。
近7日
该标签近一周分数走势小图，便于看升势 / 回落。
今日构成（饼图）
仅「细分风向」显示：今日上榜标签按套路 / 萌属性 / 作品宇宙 / 关系 / 题材等类型占比。点击图例可筛选。
