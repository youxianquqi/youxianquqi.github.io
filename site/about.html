关于本站

本站默认展示细分二次元风向，另有同人/IP与频道分榜；数据由 novel-heat 权威合成后同步，并非任何平台官方榜单。

这是什么

「次元热度」是一个二次元网文 / 轻小说 / 漫画细分标签热度趋势站。它回答的问题不是「哪本书最火」，也不是「轻小说频道是否热闹」，而是「哪类细分题材 / 套路 / IP / 同人结构正在发热」：综漫是不是又起来了、某个作品宇宙是否升温、百合或无 CP 关系是否在多源同时出现。

目标用户是写手、编辑与二创向读者——花一分钟扫一眼题材风向，而不是追单本书。

数据来源与更新

  • 采集与综合计算在 novel-heat/；本站用 node scripts/sync-from-novel-heat.js 复制权威 public JSON，不再二次重算综合分。
  • 默认「细分风向」排除轻小说 / 同人 / 漫画 / 魔幻 / 战斗 / 恋爱等频道与粗题材；它们在「频道/粗题材」Tab 单独展示。
  • 「同人/IP」榜只汇总作品宇宙、同人结构与关系类型，反映公开专区中这些标签的相对出现度，不是作品销量或阅读量。
  • 主源：刺猬猫、SF轻小说（菠萝包）、起点专区；辅助：晋江、B漫。萌娘百科只建词典。飞卢仅作观察源，不进默认综合榜。
  • LOFTER（登录墙）、番茄（SPA）暂不采。
  • 细分榜可按套路 / 萌属性 / 作品宇宙 / 关系 / 题材筛选；同人榜可按作品宇宙 / 同人结构 / 关系类型筛选。

综合分算法（细分默认榜）

各源 raw_heat 量纲不同：先在源内 min-max 到 0–100，再乘 heat_metric 与信号类型系数（结构化 API 标签 > 平台标签 > 标题推断）。

只对细分标签做默认综合；同一标签取命中源均值，未命中源不计 0。单源标签封顶，避免单源粗冠军冒充共识；多源命中加共识奖励，并标注「多源共识」；单源标注「单源发现」。行内可附证据摘要（如「2 个结构化标签 + 1 个标题推断」）。

同人/IP 榜单独合成；频道榜单独合成，反映专区/粗题材覆盖，不等价于读者热度。分数条按当前榜单相对缩放；圆点表示覆盖平台。

周聚合规则

  • 周视图按 ISO 周（周一为一周起点）聚合。
  • 每周取值：该周内最后一个有数据日的分数（末日值），不做平均，避免周末未更新时趋势被稀释。
  • 某天缺数据时折线留断点，不向前填充假数据。

免责声明
