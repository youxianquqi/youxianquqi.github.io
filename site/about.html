关于本站

本站展示的是对公开二次元专区标签/分类的汇总（采集自 novel-heat，题材+IP）；并非任何平台官方榜单，不构成追书或创作建议。

这是什么

「次元热度」是一个二次元网文 / 轻小说 / 漫画标签热度趋势站。它回答的问题不是「哪本书最火」，而是「哪类二次元题材/IP 正在发热」：综漫是不是又起来了、原神同人这周掉了多少、某个标签在几个源同时上榜。

目标用户是写手、编辑与二创向读者——花一分钟扫一眼题材风向，而不是追单本书。

数据来源与更新

  • 采集在仓库 novel-heat/；用 node scripts/sync-from-novel-heat.js 同步并构建。
  • A 期聚焦标签/题材风向：刺猬猫同人、SF 轻小说为主；经 ACG 词典（题材/套路/萌属性/IP）过滤，排除都市/爽文等。
  • 萌娘百科仅用于扩充本地属性词典（词条名），不当热度源；百科不可用时用种子词典兜底。
  • 首页可按「全部 / 套路 / 萌属性 / IP / 题材」筛选；词典有词但源站未出现则不上热度榜。

综合分算法

各源榜单的原始热度（raw_heat）量纲不同，不能直接相加。本站按名次在每个源内部归一化：

score = (1 - (rank - 1) / N) × 100，即第 1 名约 100 分，榜尾趋近 0 分。

综合榜对同一标签取所有命中源的分数均值——没上榜的源不计 0、不惩罚，因此「单源爆款」和「多源共识」都能在综合榜被看到，命中源数会单独标注。

榜单里标签右侧的分数条按当前榜单的最高分与最低分做相对缩放，不是 0–100 的绝对刻度。归一化后的分数在头部高度聚集，绝对刻度会让前几名看起来几乎一样长；相对刻度只用于比较同一屏内的高低，跨榜单不可直接比长度。标签名后的圆点对应各数据源，实心表示该平台当日在榜。

周聚合规则

  • 周视图按 ISO 周（周一为一周起点）聚合。
  • 每周取值：该周内最后一个有数据日的分数（末日值），不做平均，避免周末未更新时趋势被稀释。
  • 某天缺数据时折线留断点，不向前填充假数据。
